# 安全测试矩阵（先认证，再权限，再输入）

## 目的

安全测试不是“跑个扫描器”。扫描器发现已知模式；权限矩阵和业务逻辑用例发现越权与数据泄露。两者都要有。

## 认证（AuthN）

| 用例 | 预期 |
|---|---|
| 无 token 访问受保护接口 | 401/403，无数据泄露 |
| 过期/伪造 token | 401，不泄露内部信息 |
| 错误密码 | 统一错误文案，不暴露用户是否存在 |
| 验证码缺失/错误/过期 | 拒绝；启用时不可绕过 |
| 连续失败/账号锁定 | 按策略锁定，错误计数可恢复 |
| 刷新 token 轮换/重放 | 旧 token 失效，重放被拒 |
| 退出登录后旧 token | 失效 |

## 权限（AuthZ）

| 用例 | 预期 |
|---|---|
| 垂直越权：普通用户调用管理员接口 | 403，无副作用 |
| 水平越权：用户 A 访问用户 B 的资源（IDOR） | 403/404，不返回他人数据 |
| 租户隔离：租户 A 访问租户 B 数据 | 拒绝；响应头/查询参数不能绕过 |
| 数据权限：不同角色/部门可见范围 | 只返回授权范围 |
| 菜单/按钮权限 | 无权限不显示/不可调用，后端仍校验 |
| 角色变更后旧会话 | 权限即时失效或按策略处理 |

## 输入与文件

| 用例 | 预期 |
|---|---|
| SQL 注入（搜索/排序/筛选/路径参数） | 参数化查询；无报错泄露/数据越权 |
| XSS（富文本/公告/昵称/文件名） | 转义/过滤；存储型不执行 |
| 路径穿越（文件下载/上传/导入） | 不能读写授权目录外文件 |
| 文件上传（类型/大小/双扩展名/内容） | 白名单校验；不落地可执行文件 |
| SSRF（URL 导入/回调/图片抓取） | 禁止内网/元数据地址 |
| 批量赋值（mass assignment） | 只更新允许字段；不能提权/改租户 |
| 反序列化/模板注入（如适用） | 不接受不可信对象/模板 |

## 敏感数据

- 密码、token、验证码、Cookie 不出现在响应、日志、报告、截图。
- 字段加密/脱敏按项目约定；列表/详情/导出都要检查。
- 错误信息不泄露堆栈、SQL、内部路径、账号是否存在。
- 导出/下载/分享链接检查越权与过期。

## 扫描器

| 工具 | 覆盖 | 触发 |
|---|---|---|
| 依赖扫描（Trivy/OSV/Dependabot） | 已知漏洞依赖 | 每次 PR/夜间 |
| SAST（Sonar/CodeQL） | 代码模式 | 每次 PR |
| DAST（ZAP baseline） | 运行中 Web 漏洞 | 夜间/发版前 |
| 密钥扫描 | 硬编码凭据 | 每次 PR |

## 严重度与门禁

- **Critical/High**：必须修复或明确豁免；未处理不得放行。
- **Medium**：有结论（修复/接受/计划），写进报告。
- **Low**：进 backlog，不阻断。
- 扫描器结果必须附报告与复现；不把“扫描通过”当成“没有安全问题”。

## 证据

- 请求/响应（脱敏）、截图、扫描器报告、复现步骤、影响说明。
- 每个发现写清：位置、触发条件、影响、严重度、修复建议、验证方式。
- 只在测试环境做破坏性验证；生产只做只读/低风险检查。
